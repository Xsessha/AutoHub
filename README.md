# AutoHub Pro — автомобільний журнал

Невелика WPF-програма українською мовою для обліку заправок, техобслуговування, ремонту та інших витрат на автомобіль.

## Можливості

- Додавання й редагування записів (двічі натисніть запис у таблиці).
- Видалення вибраного запису з підтвердженням.
- Пошук за авто, описом, типом події та пробігом; сортування натисканням заголовка стовпця.
- Фільтр за типом події та швидке сортування: дата (нові/старі спочатку), пробіг або сума витрат.
- Вибір дати для кожної події, зокрема для внесення попередньої історії обслуговування.
- Нагадування про наступне ТО за пробігом із попередженням, коли воно наближається або прострочене.
- Автозбереження журналу між запусками та імпорт/експорт файлів JSON.
- Підрахунок витрат за поточний місяць і середньої витрати пального.
- Стовпчикова діаграма витрат за останні шість місяців із сумами та підказками.
- Калькулятор потрібного пального й орієнтовної вартості поїздки.
- Перевірка даних із підтримкою десяткової коми та крапки.

## Запуск

Потрібен Windows і .NET 9 SDK. Відкрийте `AutoHubPro.csproj` у Visual Studio та натисніть **F5**, або виконайте з папки проєкту:

```powershell
dotnet run
```

## Коротка інструкція

1. Заповніть авто, тип події, дату, пробіг, суму витрат і опис. Для події ТО можна додати плановий пробіг наступного обслуговування. Витрату пального можна вказати для заправки або розрахунку поїздки.
2. Натисніть **Додати до журналу**. Запис з'явиться в таблиці та буде збережений автоматично.
3. Для редагування двічі натисніть потрібний рядок, змініть дані й натисніть **Зберегти зміни**.
4. Для видалення виберіть рядок і натисніть **Видалити**. Підтвердіть дію.
5. Скористайтеся фільтром **Подія** та меню **Сортувати**, щоб знайти записи ТО, ремонту чи заправки, відсортувати їх за датою, пробігом або витратами. Кнопка **Скинути фільтри** повертає повний список.
6. Діаграма показує сумарні витрати в кожному з останніх шести місяців; наведіть курсор на стовпчик, щоб побачити точну суму.
7. Нагадування **ТО** в заголовку діаграми повідомить, скільки кілометрів залишилось до планового обслуговування або на скільки кілометрів воно прострочене. Для нагадування заповніть поле планового пробігу в записі ТО.
8. У калькуляторі введіть відстань, витрату л/100 км та ціну літра й натисніть **Розрахувати вартість**.
9. **Експорт JSON** створює резервну копію, а **Імпорт JSON** замінює поточний журнал даними з вибраного файла.

Автозбереження розміщує дані у `%LOCALAPPDATA%\AutoHubPro\records.json`. Десяткові числа можна вводити через кому або крапку. Витрати та пробіг задаються для події; середня витрата обчислюється за записами, у яких вона вказана.
